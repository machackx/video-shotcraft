## 1. 视觉方向

**选定方向：「晴空工作台」——直接从产品自身长出来的浅色企业蓝。** 底色是站点的雾白蓝，界面以真实截图出现，
文字、字幕、标注、光效全部使用站点 tokens；只有收尾的品牌峰值借用站点 CTA 区的深海军蓝渐变做反差。

备选（未选）：B「深海军蓝夜场」——全片用 CTA 深蓝做暗场霓虹，炫但偏离站点整体浅色调；C「纸面简报」——
暖白纸张 + 衬线，与产品现代无衬线风格冲突。

**跳过 styleframe 的理由**：官网本身就是严格的品牌规范（字体、色板、圆角、图标库均从 computed styles 与
资源直接提取），且片中界面全部是真实截图；字体与配色在阶段 5 首批静帧中逐镜验证。

### 视觉 tokens（站点 computed styles 实测）

| token | 值 | 用途 |
|---|---|---|
| bg | `#F7F9FC`（body）/ `#F2F6FC` | 全片底色 |
| surface | `#FFFFFF`，描边 `#E6ECF5` | 卡片 / 胶囊 |
| ink | `#102146`（标题）/ `#162133`（正文） | 标题、字幕 |
| muted | `#667085` / `#7D8CA4` | 副文 |
| accent | `#2F7CFF` | 主强调（按钮、数据包、强调缝、落定染色） |
| indigo | `#5267DF` | 次强调 |
| 能力色 | 绿 `#25B96F` · 紫 `#8B5CF6` · 橙 `#F79009` · 青 `#15A9C7` | 六大能力图标底色，只在对应元素出现 |
| logo 渐变 | 蓝 `#017FF7` → 绿 `#01D696` | 标志、品牌峰值光 |
| navy CTA | `#13295A → #1E4FB8` 渐变 | 收尾舞台背景 |
| 字体 | Noto Sans SC 400 / 500 / 700（站点栈 PingFang SC → Microsoft YaHei → Noto Sans SC） | 全片 |
| 圆角 | 卡 16–20px，按钮 10px，胶囊全圆 | |
| 图标 | Lucide 线性图标（站点同款，stroke 2） | 来源节点、标注 |

### 动效性格 tokens（预设「专业信赖」，向「亲和」微调）

- 能量轴：低-中（企业 B2B）；调性轴：严肃偏友好（圆角 + 亮蓝）。
- 主时长 ~21f；淡入 / 推移类 `bezier(0, 0, 0.2, 1)`，不过冲；**落地类动作**（行嵌入、chip pop、合影落位）保留各卡调校过的过冲（y1>1）。
- 三个词：稳、清晰、轻盈 —— 与「专业 · 高效 · 安全 · 协同」对得上。
- 不加手持抖动（Q3）；光效只给主角一次且裁进圆角（Q4）。

## 4. 声音与卡点（阶段 6）

- **BGM**：`assets/audio/bgm/cat-walk.mp3`（Arulo · House · Mixkit 免费可商用）。选它的依据是实测结构而非听感：
  130.0 BPM、网格残差 ≤9 ms（候选中最干净）、低 → 中 → drop 的清楚段落，正好对上本片「低开 → 功能爬升 → 中段高点 → 峰值收尾」。
  **未经人耳试听**（制作环境只能做测量），交付时如实说明。
- **卡点**：片头 = 歌曲第 15 拍（7.170 s），片内第 k 拍 = 歌曲第 k+15 拍。所有硬切钉整拍：
  S3 第 22 拍（白闪 #1，kick 1.06）· S4 第 34 拍 · S5 第 41 拍 · S6 第 48 拍（白闪 #2 = 歌曲 drop）·
  S7 第 66 拍 · S8 第 78 拍 · S9 字标压印第 94 拍（终检后 S6 悬停段延长 42f，下游切点顺延到新的强拍）。渲后回测见 `analysis/beat-check.json`。
- **全画面冲击 ≤3（R4）**：只有两处白闪（间隔 26 拍）；S6→S7、S7→S8 改用底色过渡（dip），收尾压印是元素层。
- **SFX**：Freesound 在制作环境被站点 403（site / apiv2 / cdn 均拒绝），按 sfx-sourcing.md 不绕过、不用旧库，
  改为 `scripts/make-sfx.py` 确定性合成原创音效（whoosh / riser / impact / shimmer / 玻璃轻触 / 键盘 / 机械 tick / 柔和提示铃），
  manifest 附每条的 Freesound 检索词，网络可用时可替换。S5 待办行按卡片规定不逐条配音（靠强调色缝做视觉拟音）。
- **对齐**：输出音轨偏移实测 1.27 f（8 个探针，极差 0.02 f，`analysis/av-offset.json`），SFX `from` 统一扣除；
  BGM 用 `scripts/cut-bgm.py` 预裁（起点多裁 1.27 f），成片与工作台共用。
- **响度**：总线 +5 dB，目标约 −17 LUFS、true peak ≤ −1 dBTP；交付带 BGM 与无 BGM（保留 SFX）两版。

## 5. 有意识的偏离 / 适配记录

- 各 demo 的品牌件（video-shotcraft 标志、琥珀 / 赤陶 / 紫色强调）全部换成企悦标志与站点 tokens。
- crane-rise-reveal 追踪对象由「表格行」改为看板 KPI 行（看板为卡片网格而非表格），行洗光按卡片行带触发。
- exploded-view 五层构件来自门户登录页的工作台示意（DOM 元素逐块截图）；标注文字 ≥32px（Q11）。
- radial-ripple-phone-chips 的屏内 feed：真实手机截图仅一屏，滚动行程按截图实际可滚高度缩短，避免滚到底露白（卡片已知坑）。
- 收尾舞台用站点 CTA 区的深海军蓝渐变（站点自有色），粒子改为冷白 / 浅蓝，不用金尘。
- radial-ripple-phone-chips：真实手机截图只有一屏、没有下文，**不做假滚动**（卡片已知坑：滚到底露白），
  改为屏内铃铛 / 消息两个真实角标在对应悬浮卡弹出时各 pop 一次，承担「里面有内容在跑」。
- bezier-source-converge-merge / exploded-view：动画时基保持 demo 原长（168f / 170f），多出的时长全部是结语 / 海报静止 hold（R1）。
- glass-pill-dictation-typing：中文 10 字按真人听写语速 5 f/字（卡片原值 2 f/字对应 28 个英文字符）。
- vertical-word-roll-blur-cycle：卡点后镜头 163 f（demo 150 f），归一化进度跟镜头时长缩放，比例窗不变。
- 镜头时长随卡点微调（见 `src/timeline.ts` 的 CUTS），每镜验收帧同步在 `QA_FRAMES`。
- exploded-view：机位比例 0.62→0.50（demo 0.56→0.47）、下移 cy 30→150 + 收尾 80——本页 1600×768 比 demo 矮，放大一档才撑住画面；
  中文两行标注阅读量大，标注错峰 6→5f、悬停段延长 42f，五条全亮 ≥2s；「收支概览」层左缘紧贴侧栏，按外缘锚点引线会横穿侧栏（卡片已知坑），
  改挂右栏、锚在费用趋势右缘；侧栏抬起后的底板槽位铺工作台底色；预备下压改为整组下移（demo 的 z 下压会让层沉到底板之下、页面变空）。
- 小字作纹理（Q11 允许的两态之一）：S3 全景看板、S6 轴测页面、S7 手机屏、S9 合影卡片里的界面小字是截图纹理，不作为要读的文字；
  要读的文字（字幕 58px、标注 44/32px、标题、悬浮卡 2.4× 后 ≥32px、收尾网址 44px）全部达标。
- 手机屏内是官网原图的真实状态（多处 0 / -- / 暂无新消息），不改写数据；靠两侧悬浮卡（待办 12 / 消息 92）表达"有内容在跑"。
- Q2 纹理倍率：S3 起点特写约 1:1、S5 约 1.4×（低于 2× 的推荐值），逐帧放大检查无像素方块，接受。
- 文案出处：除「项目、人员与经营数据，一屏掌握」「流程审批：待办与进度，实时可见」两条字幕、AI 胶囊问句与各处标注是按画面撰写外，
  其余文字均取自官网 / 门户登录页原文（「业财一体」= 登录页「业务财务一体化」「业财一体 · 业务驱动 · 财务联动」；
  副标改写自登录页「实现审批、合同、开票、收付款、报销等一体化管理」）。发布前建议产品方过目一遍宣传口径。
